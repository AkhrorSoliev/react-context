# React Context API ⚛️ + E-Commerce App (Pure CSS)

Ushbu kursda biz **React Context API** yordamida kichik bir e-commerce ilovasini quramiz va stilizatsiya uchun faqat CSS-dan foydalanamiz. Kurs davomida mahsulotlar ro‘yxati, savat (cart) funksiyalari va holatni boshqarishni o‘rganamiz.

## 📖 Loyihaning Mazmuni

1. **Kirish va Loyiha Muhitini Tayyorlash**

   - React ilovasini yaratish (Vite yoki Create React App yordamida).
   - Loyihaga kerakli kutubxonalarni o‘rnatish:
     - `react-router-dom` – Routing uchun.
     - `react-icons` – Ikonalar uchun.

2. **React Context API ni Loyihaga Qo'shish**

   - `Context` va `Provider` ni yaratish.
   - Global holatni boshqarish:
     - Mahsulotlar ro‘yxati.
     - Savat (Cart) ma'lumotlari.

3. **Mahsulotlar Ro'yxatini Namoyish Qilish**

   - Statik mahsulotlar ro‘yxatini yaratish.
   - Mahsulotlarni `Context` orqali o‘qish va UI da ko‘rsatish.
   - CSS yordamida mahsulot kartalari uchun dizayn yaratish.

4. **Savatni (Cart) Yaratish**

   - Mahsulotni savatga qo‘shish funksiyasini yozish.
   - Savatga qo‘shilgan mahsulotlarni real vaqt rejimida yangilash.
   - Savatdagi mahsulotlar sonini hisoblash.

5. **Savatchani Boshqarish (Cart Management)**

   - Mahsulotni savatdan o‘chirish.
   - Savatdagi mahsulotlar sonini oshirish yoki kamaytirish.
   - Jami narxni (Total Price) va Jami soni (Total Amount) hisoblash.

6. **React Router Yordamida Sahifalarni Yaratish**

   - Home (Bosh sahifa) – Mahsulotlar ro‘yxati.
   - Cart (Savat) – Savatcha va umumiy hisob-kitob.
   - Contact (Biz bilan aloqa) – Oddiy matnli sahifa.

7. **UI Dizaynini Yaxshilash (Pure CSS)**

   - CSS yordamida mahsulot kartalarini tartibga solish (`grid` yoki `flexbox` bilan).
   - Savat sahifasi uchun maxsus dizayn yaratish.
   - Tugmalar, yozuvlar va boshqa elementlarni chiroyli qilish uchun CSS effektlar qo‘shish.

8. **Qo‘shimcha Funksiyalar Qo‘shish**
   - Filter va qidiruv funksiyasi.
   - Savatni tozalash (Clear Cart) tugmasi.
   - Mahsulotni maxsus xususiyatlar (rating, kategoriya) bilan ko‘rsatish.

## 💡 Amaliy Maqsad

Darslar davomida biz quyidagi amaliy maqsadga erishamiz:

- **Kichik e-commerce ilovasi** yaratish.
- **React Context API** orqali holatni boshqarish.
- Routing yordamida sahifalarni bog‘lash.
- Faqat CSS yordamida UI dizaynini yaratish.
